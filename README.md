# 识日生词本 - Tampermonkey 油猴脚本

日语学习者划词翻译+收藏工具，支持一键同步到识日 App。

## 功能

| 功能 | 说明 |
|------|------|
| 划词翻译 | 选中日语文本，自动弹出翻译结果（支持 MyMemory / DeepSeek AI / 自定义 API） |
| 一键收藏 | 弹窗中点击「收藏」保存原始日文单词，自动去重 |
| 单词列表 | 浏览器右上角绿色「识」图标，可拖动到任意位置，点击查看全部收藏 |
| 删除单词 | 列表中每个单词右侧有删除按钮，支持移除误添加的条目 |
| 导出 TXT | 一键导出 UTF-8 无 BOM 纯文本生词本 |
| 同步到识日 | 通过 WiFi 将单词本上传到识日 App |

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开 [识日生词本.user.js](./识日生词本.user.js)，点击 Raw 或直接复制全部内容
3. Tampermonkey 会自动弹出安装页面，点击「安装」即可

## 使用

- **划词翻译**：在任意网页选中含日语假名或汉字的文本，弹窗自动出现
- **收藏单词**：弹窗中点击绿色「收藏」按钮
- **查看单词本**：点击右上角可拖动的绿色「识」图标
- **删除单词**：单词本中点击单词右侧的 `×`
- **导出**：红色「导出TXT」按钮
- **同步到识日**：确保手机与电脑在同一 WiFi 下，识日 App 已开启 WiFi 导入，点击蓝色「一键同步到识日」按钮

## 设置

点击单词面板中的齿轮图标 ⚙ 进入设置：

- **翻译 API**：三选一
  - MyMemory（免费，无需密钥，默认）
  - DeepSeek AI（需在 [platform.deepseek.com](https://platform.deepseek.com/api_keys) 申请 API Key，翻译质量更优）
  - 自定义 API（填入任意 GET 接口地址，用 `{text}` 占位查询词）
- **WiFi 同步地址**：修改识日 App 的上传地址

## 技术

- 纯前端实现，使用 `GM_setValue` / `GM_getValue` 本地存储
- `GM_xmlhttpRequest` 处理跨域 API 请求和文件上传
- 单词本数据仅存储在浏览器本地，不会上传至任何第三方服务器（WiFi 同步除外）
